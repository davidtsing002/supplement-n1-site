# 验真派 · 官方网站

「验真派」是保健品的**买方代理人**：用 N-of-1 个人盲法试验，在 6 周内告诉你一款补剂到底**对你**有没有用。我们的铁律是**绝不卖产品、绝不抽佣**——只要开始卖，信任基础就崩了。

本仓库是验真派的官方营销站点（静态单页，零依赖，可直接部署到 GitHub Pages）。

## 站点结构

```
supplement-n1-site/
├── index.html      # 单页站点（理念 / 怎么验证 / 科学 / 壁垒 / 试运营 / FAQ）
├── styles.css      # 设计系统与响应式样式
├── app.js          # 移动端菜单、滚动渐显、试运营意向表单
└── README.md
```

## 本地预览

无需任何构建步骤，任选一种：

```bash
# 方式一：直接用浏览器打开
open index.html

# 方式二：起一个本地静态服务器
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 设计要点（与商业逻辑对齐）

- **买方代理人定位**：首页即声明「不卖产品，只验证」，并把「利益隔离信任垄断」作为最强壁垒呈现。
- **盲法在呈现层**：说明统一容器自盲、密钥由平台保管，不需品牌配合即可真盲。
- **个人即答案**：强调先用单个人的 N-of-1 结果穿越死亡谷，而非靠网络。
- **试运营转化**：睡眠 / 代谢两类目先跑 concierge MVP，表单收集种子用户意向（本地存储）。
